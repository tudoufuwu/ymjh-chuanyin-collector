# 隐私与数据保留

聊天归档可能包含玩家名称、角色 ID、聊天文本、时间和频道。这些都可能是个人数据或受平台规则约束的信息。

## 默认策略

- 将原始 JSONL、SQLite、日志和备份仅留在 `var/`；
- `.gitignore` 阻止这些数据进入源代码仓库；
- 网页默认只监听 `127.0.0.1`；
- 默认采集输出不含地址、完整序列字段或会话样式信息；
- 不提交官方资源、截图、抓包或第三方二进制。

## 你的责任

- 只处理你有权访问和保留的数据；
- 根据所在地区法律、游戏服务条款和所在社群规则确定保留期限；
- 将备份加密，不在 Issue、PR、截图或网页 Demo 中公开真实聊天；
- 不要将数据库、WAL/SHM、JSONL、`.env`、`.clixml`、日志或诊断输出推送到 GitHub；
- 删除本地数据前先确认自己是否已完成安全备份。

## 最小化

需要分享 Bug 时，优先构造合成 JSONL。仓库的 `examples/synthetic-events.jsonl` 是唯一允许提交的 JSONL 类型示例。任何需要真实数据才能复现的问题，都应先去除姓名、ID、正文、时间、路径、地址和会话信息。
